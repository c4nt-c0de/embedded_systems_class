# STM32 Embedded Systems Projects Workspace

This repository contains university embedded systems laboratory tasks built for the STM32VL Discovery evaluation board (ARM Cortex-M3) using Keil uVision without heavy HAL frameworks.

## Projects Overview

- **`7seg_disp/`** — A staircase timer control unit featuring a multiplexed dual 2-digit 7-segment display driven by cascaded `74HC164` shift registers and local tactile push-button configuration.
- **`lcd_uart/`** — An advanced staircase timer control unit featuring a 2x16 character LCD (HD44780 controller) interfaced via a shift register, an incremental rotary encoder with push-button integration, and a serial UART communication channel for terminal control and non-volatile flash parameter storage.
